# Website Logo Directory

Drop your circular website logo image file into this folder.

### Supported File Names & Formats:
You can place your image here with any of these names:
- `logo.png` (Recommended for transparent circular graphics or photos)
- `logo.jpg` or `logo.jpeg`
- `logo.svg` (Recommended for vector icons)
- `logo.webp`

### How it works:
- The website automatically renders any image placed here in a circular frame (`rounded-full`) across the navigation bar, hero banner, and favicon.
- If you add `logo.png` (or `.jpg` / `.svg` / `.webp`), the app will display it automatically without needing any code changes.
